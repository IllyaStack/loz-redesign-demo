# LOZ — Website Redesign Demo

**An independent website redesign concept** focused on a responsive presentation and a clear, maintainable frontend structure.

[Source code](https://github.com/IllyaStack/loz-redesign-demo)

> **Portfolio status:** Demo / redesign concept. This repository is not evidence of an official website launch or a completed paid client engagement.

## Overview

The project explores a refreshed visual presentation for a business website using a lightweight static frontend. It separates page structure, styling, behaviour, and configuration rather than relying on a heavy framework or build system.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Static assets in `images/`

## Repository structure

```text
index.html    Page layout and content
styles.css    Visual styling and responsive layout
script.js     Frontend interactions
config.js     Project configuration
images/       Visual assets
```

## Run locally

Clone the repository and start a local server from the project directory:

```bash
python3 -m http.server 8000
```

Open **http://localhost:8000**. For simple inspection, `index.html` can also be opened directly in a browser.
